# Contributing

Fork, branch, PR. Keep it simple.

## Setup

```bash
git clone https://github.com/lakshyabuilds/gargi.git
cd gargi
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -e .
```

## What to work on

- Check issues for `good first issue` labels
- Or just use GARGI, find something annoying, fix it
- Selfish PRs are the best PRs

## Guidelines

- Python 3.10+, type hints where helpful
- Test on Windows AND macOS/Linux if touching TUI or voice
- Pure ASCII only for face art (cmd.exe compatibility)
- Keep commits small and descriptive

## Style

- `snake_case` for functions/variables
- `UPPER_CASE` for constants
- `_leading_underscore` for private
- Comments explain *why*, not *what*
